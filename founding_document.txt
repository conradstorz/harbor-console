Harbor Console

Vision

Harbor Console is a lightweight terminal dashboard for Linux servers.

Its purpose is simple:

Replace the default Linux login console with a useful operationaldashboard.

Engineering Principles

MVP First

YAGNI

KISS

DRY

Test Driven Development

Main is Always Deployable

MVP (v0.1.0)

The first release shall display:

Hostname

Uptime

CPU utilization

Memory utilization

Disk utilization

IPv4 address

Docker container count

Current date/time

The display refreshes once per second.

The application exits cleanly with Ctrl+C.

No configuration files.

No plugins.

No colors are required.

No keyboard shortcuts.

No historical graphs.

No databases.

No web server.

Release Criteria

The project is complete when:

It automatically starts.

It continuously updates.

It never crashes during normal operation.

The Linux login console is no longer preferred.

"Is my server healthy?"
